# Protocol Photo Examples

These compressed screenshots document the repeatable field-photo protocol. The original full-resolution screenshots are kept outside the repository; this folder contains the current public documentation copies.

The annotations show:

- site identifier and working site name
- establishment date
- photo type and zoom
- standing location
- gridline alignment instructions
- repeatable visual anchors such as fence posts, road edges, signs, trees, and utility poles

## Protocol Manifest

[photo_manifest.tsv](photo_manifest.tsv) records both the current public assets and older archive-only views. Site 7 currently has only an updated right-context image in the public gallery; Site 8 has updated wide and left-context images. The remaining legacy views stay listed for traceability until revised copies are supplied.

These images are protocol documentation, not model-training data. Raw field photos and full-resolution exports should stay out of Git unless intentionally curated for public release.
